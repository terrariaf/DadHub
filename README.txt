DadHub iPhone Edition — Progressive Web App


- This is a home-screen web app, not an App Store native iOS binary.
- Data is stored locally on each device, not synced. Watch List > Export Backup saves a JSON backup.
- Clearing Safari website data or removing the web app can erase local data.
- GitHub Pages public repositories expose source files publicly. Do not add personal secrets or private family information to the code.
- Safari's Add to Home Screen requires hosting over HTTPS for the service worker/offline support.
