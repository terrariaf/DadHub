DadHub iPhone Edition — Progressive Web App

HOW TO PUBLISH (FREE)
1. Create a free GitHub account and a new PUBLIC repository (e.g. dadhub).
2. Upload the contents of this folder to the repository root (not the ZIP itself).
3. In repository Settings > Pages, choose Deploy from a branch, main, /(root), and Save.
4. Wait for the HTTPS Pages URL to appear, usually https://YOURNAME.github.io/dadhub/.
5. Open that URL in Safari on the iPhone. Tap Share > Add to Home Screen > Add (or Open as Web App if prompted).
6. Open DadHub from its new home screen icon. After the initial online load it can work offline.

NOTES
- This is a home-screen web app, not an App Store native iOS binary.
- Data is stored locally on each device, not synced. Watch List > Export Backup saves a JSON backup.
- Clearing Safari website data or removing the web app can erase local data.
- GitHub Pages public repositories expose source files publicly. Do not add personal secrets or private family information to the code.
- Safari's Add to Home Screen requires hosting over HTTPS for the service worker/offline support.
